Build your own

Arena Academy and Arena Card follow the same pattern: call the API from your server, cache what changes slowly (hero lists, academy data) for a few minutes, and pass the player's JWT through only for /api/user requests.

Start from the playground to find the response shape you need, then copy the generated snippet in your language. The sign-in tutorial walks through the JWT flow Arena Card uses.
