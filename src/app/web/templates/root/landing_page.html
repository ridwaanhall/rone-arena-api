First request

Hero names work anywhere a hero ID does, so miya, Miya, and 1 return the same hero.

curl "{{ api_url }}/heroes/miya/counters?days=7&rank=mythic"
const res = await fetch("{{ api_url }}/heroes/rank?days=7&sort_field=ban_rate");
const { data } = await res.json();
for (const row of data.records) {
    console.log(row.data.main_hero.data.name, row.data.main_hero_ban_rate);
}

Responses keep the upstream shape: code is 0 on success and rows sit in data.records[].data.
