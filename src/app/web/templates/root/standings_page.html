Matches

Choose a result for any match. Each match is first to 2 games, so it ends 2-0, 2-1, 1-2 or 0-2. Matches you change are marked.

    How the table is ranked

    Every league here plays first to 2 games. A team earns one match point for each match it wins, whatever the score.

    1. Most match points ranks higher.
    2. If points are level, the better game difference ranks higher (games won minus games lost).
    3. If that is level too, the teams' matches against each other decide: more wins between them, then the better game difference between them.
    4. If they are still level, the league plays a tiebreaker match. The table marks these teams as tied.

    These rules rebuild the official Indonesian and Philippine tables exactly. Game difference comes before the result between two teams: a team can lose to another and still finish above it.

    A season has as many weeks as teams, and every team meets every other team twice. In a custom league the schedule is made for you the same way. The teams that miss the playoffs are the ones at the bottom of the table: the last 3 in Indonesia, the last 2 in the Philippines, and the number you choose in a custom league.

    The status column shows what a team can still reach. Clinched means it is certain to make the playoffs, Eliminated means it cannot. Alive means it is not decided yet. Before the season ends the check is careful, so a team can read Alive when it is in fact already decided, but never the other way round.
